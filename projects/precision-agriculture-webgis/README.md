# Precision Agriculture WebGIS Platform Evaluation

**Project focus:** WebGIS, online mapping, precision agriculture, platform comparison

**Platforms:** MangoMap · ArcGIS Online · CARTO

## Overview

This project evaluated three web-mapping platforms for precision-agriculture applications using a Knock Farm crop-management theme. The work compared the platforms from both technical and usability perspectives, with attention to interface design, spatial-analysis tools, visualisation, sharing, collaboration, and suitability for dynamic or real-time data.

The project workflow involved researching precision agriculture, selecting the Knock Farm dataset, studying MangoMap, ArcGIS Online and CARTO, creating comparable web maps, analysing each platform, and preparing recommendations.

## Objectives

- Compare the features, functionality and ease of use of MangoMap, ArcGIS Online and CARTO.
- Create agricultural web maps that highlight differences between the three platforms.
- Assess the platforms' ability to support dynamic data feeds and sensor-based visualisation.
- Explore crop-yield variability mapping using high-resolution satellite and precision-agriculture data.
- Consider usability from the perspective of agricultural end users.

## Methodology

1. Researched the precision-agriculture use case.
2. Selected a common farm-management dataset and theme.
3. Created comparable interactive web maps in each platform.
4. Compared interface design, ease of use, functionality, geoprocessing and visualisation.
5. Assessed suitability for real-time and dynamic data.
6. Summarised strengths, limitations and platform recommendations.

## Key findings

### MangoMap
MangoMap was assessed as the most straightforward option for users who prioritise ease of use. The project highlighted its intuitive interface, simple layer controls, map styling, sharing options and user-friendly analysis tools such as queries and heatmaps.

### ArcGIS Online
ArcGIS Online was assessed as the strongest platform for advanced GIS functionality. The project highlighted its wider range of spatial-analysis capabilities, data integration options and connection to other Esri applications, while also noting a steeper learning curve.

### CARTO
CARTO was assessed as a useful balance between simplicity and analytical visualisation. The project particularly highlighted dashboard-style presentation, widgets, interaction and suitability for dynamic or real-time visualisation.

## Conclusion

The project concluded that platform choice should depend on the user's GIS experience and the requirements of the application:

- **MangoMap** for simplicity and accessibility.
- **ArcGIS Online** for advanced GIS analysis and broader functionality.
- **CARTO** for an accessible web-mapping workflow with strong visualisation and dashboard capabilities.

For projects involving sensor or IoT integration, the study identified ArcGIS Online and CARTO as promising options, while noting that further testing would be appropriate.
