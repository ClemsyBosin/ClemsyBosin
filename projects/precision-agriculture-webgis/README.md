# Precision Agriculture WebGIS Platform Evaluation

**Project focus:** WebGIS, online mapping, precision agriculture, platform comparison

**Platforms:** MangoMap · ArcGIS Online · CARTO

## Overview

This project evaluated three web-mapping platforms for precision-agriculture applications using a Knock Farm crop-management theme. The work compared the platforms from both technical and usability perspectives, with attention to interface design, spatial-analysis tools, visualisation, sharing, collaboration, and suitability for dynamic or real-time data.

![WebGIS project methodology](assets/webgis_methodology.png)

## Objectives

- Compare the features, functionality and ease of use of MangoMap, ArcGIS Online and CARTO.
- Create agricultural web maps that highlight differences between the three platforms.
- Assess the platforms' ability to support dynamic data feeds and sensor-based visualisation.
- Explore crop-yield variability mapping using high-resolution satellite and precision-agriculture data.
- Consider usability from the perspective of agricultural end users.

## Methodology

1. Researched the precision-agriculture use case.
2. Selected a common farm-management dataset and theme.
3. Created comparable interactive web maps in each platform.
4. Compared interface design, ease of use, functionality, geoprocessing and visualisation.
5. Assessed suitability for real-time and dynamic data.
6. Summarised strengths, limitations and platform recommendations.

## Platform comparison

![Comparison of MangoMap, ArcGIS Online and CARTO](assets/platform_comparison_table.png)

### Key findings

**MangoMap** was assessed as the most straightforward option for users who prioritise ease of use, with an intuitive interface, simple layer controls, styling and sharing.

**ArcGIS Online** was assessed as the strongest platform for advanced GIS functionality, with a wider range of spatial-analysis capabilities and data-integration options, although with a steeper learning curve.

**CARTO** was assessed as a balance between simplicity and analytical visualisation, particularly for dashboard-style presentation, widgets and interactive visualisation.

## Conclusion

The project concluded that platform choice should depend on the user's GIS experience and application requirements: **MangoMap** for simplicity and accessibility, **ArcGIS Online** for advanced GIS analysis and broader functionality, and **CARTO** for accessible web mapping with strong visualisation and dashboard capabilities.
